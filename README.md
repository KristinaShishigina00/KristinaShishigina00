### АИС «Аура» · Дипломный проект

Информационная система персонализированного подбора косметических продуктов.

**Мой вклад:** анализ предметной области, формирование требований, описание пользовательских и бизнес-процессов, проектирование моделей данных и логики рекомендаций.

**Технический контекст:** PostgreSQL, REST API, RAG-компонент с векторным поиском.

**Что показывает проект:** умение связать потребности пользователя с требованиями, структурой данных и архитектурой решения.
